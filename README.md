# O's Dan — 오늘의 단어와 주제

이 세상에 존재하는 모든 주제와 단어들 중 매일 새로운 오늘의 단어를 만나고, 다양한 주제 스펙트럼에서 새로운 단어와 개념을 추출하는 웹 사이트입니다.

- **사이트 바로가기**: [https://jeondusan-cloud.github.io/odan/](https://jeondusan-cloud.github.io/odan/)

## 주요 구성
- **O's Dan**: 매일 날짜를 기준으로 선정되는 오늘의 단어 표시
